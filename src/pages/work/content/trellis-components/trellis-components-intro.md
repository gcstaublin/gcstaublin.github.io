---
title: "Equipped for change"
---

During 2025, a new visual language for HubSpot is being developed with rollout expected later this year.

On the engineering side of the design system, the team began building a new React component library that would leverage the new design token system. The new React library was primarily a 1:1 rebuild of the design system’s original library, dating back to 2015. The primary goal was leverage design tokens for design decisions and to be able to support the “flip the switch” moment later in 2025, when the new visual language is set to roll out.

On the design side, we didn’t initial have a solve for providing theming to designers.
