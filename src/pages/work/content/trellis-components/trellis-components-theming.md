---
title: "Multi-brand, multi-environment themes"
---

The new component library support the classic (Canvas) visual language, which dates back to 2015, as well as the the next (Trellis) visual language, the next iteration of HubSpot’s visual language.

The library will make it easy for designers to design in the current Canvas visual language and preview how their screen will look once Trellis begins rolling out later this year.
